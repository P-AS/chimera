option('gl_bridge', type: 'boolean', value: true,
  description: 'Build the GPU bridge into the engine: a real OpenGL context that answers a sandboxed core\'s GL calls, so a renderer can drive hardware instead of a software rasteriser. A core drawn this way is NOT deterministic - the GPU is outside the sandbox and the savestate, and differs between machines - so a movie recorded on it records that a GPU drew. Nothing uses it unless a project asks for a hardware renderer; it is on by default so that asking works. Needs EGL on Linux (libegl-dev) and opengl32 on Windows; see docs/gpu-bridge.md.')
option('qt_ui', type: 'feature', value: 'auto',
  description: 'Build Chimera\'s window and its view models (Qt 6.12: Core, Gui, Qml, Quick, QuickControls2). Built when Qt 6.12 is found; a release and CI ask for it with -Dqt_ui=enabled, so a missing Qt stops them.')
